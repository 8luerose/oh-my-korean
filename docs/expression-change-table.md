# natural-korean 표현별 교정·유지표

총 191행입니다. 첨부 MD의 대표 표현 101개, 본문·규칙에서 추가로 확인한 표현 62개, B절의 기존 교정 예문 16개, 기존 SKILL.md의 문장·단어 예시 12개를 수록했습니다. 비슷한 표현도 원자료의 표기가 다르면 별도로 남겼습니다.

**이 표는 고정 치환 사전이 아닙니다.** 조건부 예시는 이번에 만든 설계 검토용 설명이며 실제 모델 실행 결과가 아닙니다. 예시에 제시한 영어·사실이 실제 입력에 없다면 적용하지 않습니다. 자연스러운 표현과 의도적인 비유는 영어가 함께 제공되어도 유지합니다.

조건부 수정은 해당 표현이 확인된 뜻을 가리거나 잘못 전달하고, 표에 적힌 근거와 보존 조건을 모두 충족할 때만 합니다. 근거가 부족하면 유지합니다. 수정 예시에 없는 사실·행동·원인·평가를 보충하지 않습니다.

조사 자료의 인용문은 자료 그대로 보존했습니다. 아래 제안은 같은 문구가 앞으로 교정할 일반 본문에 나타난 경우의 판단입니다. 직접 인용문·코드·URL은 별도 교정 요청이 없으면 손대지 않습니다.

「번역투」「어휘」「문장 길이」처럼 범주를 가리키는 항목에는 고정된 교정 결과가 없습니다. 원자료의 검색어·계정명·URL·방법론 문장은 교정 후보에 넣지 않았습니다. 원자료 전체의 모든 한국어 단어를 나열한 표는 아닙니다.

출처 원문의 근거 성격은 실사용 경험·패러디·편집 조언·표현 목록·반례로 구분합니다. 원문의 관찰을 성능 검증이나 금지어 판정으로 바꾸지 않았습니다.

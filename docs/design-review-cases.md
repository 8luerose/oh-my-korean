# 교정 도구 제작 검수 사례

아래 여섯 사례는 설계 검토용 예시입니다. 별도 모델에 실행한 결과가 아닙니다. 기대 출력은 제작자가 보존 원칙에 맞춰 작성한 기준이며, 교정 효과의 실측값이나 개선율을 나타내지 않습니다.

코드블록은 이 문서에서 입력과 기대 출력을 구별하기 위한 표시입니다. 실제 도구는 원문에 없던 코드블록을 덧붙이지 않습니다.

## C01. 논리적 일관성을 구별하며 목록과 강조 유지

판단은 수정입니다.

대응 영어

```text
This argument is logically consistent.
```

추가 참고 사항은 다음과 같습니다.

영어 원문은 첫 번째 목록 항목에 대응한다.

한국어 입력

```text
# 검토

- 이 주장은 **단단하다**.
- 이 판단은 잠정적이다.
```

기대 출력

```text
# 검토

- 이 주장은 **논리적으로 일관된다**.
- 이 판단은 잠정적이다.
```

대응 영어가 논리적 일관성을 뜻한다. 제목·빈 줄·목록·강조 기호와 잠정적이라는 유보를 보존한다.

입력과 기대 출력 모두 마지막 줄 끝의 줄바꿈 한 개까지 포함합니다.

## C02. 근거의 충분함을 논리적 일관성과 구별

판단은 수정입니다.

대응 영어

```text
This claim is well supported by evidence.
```

한국어 입력

```text
이 주장은 단단하다.
```

기대 출력

```text
이 주장은 충분한 근거로 뒷받침된다.
```

같은 한국어 평가어라도 대응 영어가 근거의 충분함을 뜻하므로 C01과 구별한다.

## C03. 정확한 전문용어 유지

판단은 유지입니다.

대응 영어는 제공되지 않은 상황입니다.

한국어 입력

```text
이 작업의 병목은 디스크 쓰기 속도입니다.
```

기대 출력

```text
이 작업의 병목은 디스크 쓰기 속도입니다.
```

병목이 속도를 제한하는 지점을 정확하게 뜻하므로 풀어 쓰거나 바꿀 필요가 없다.

## C04. 문맥에 맞는 표현과 보호 영역 유지

판단은 유지입니다.

대응 영어는 제공되지 않은 상황입니다.

한국어 입력

```text
사진 속 글자가 선명하다.
그는 “이 주장은 단단하다”라고 말했다.

| 항목 | 값 |
| --- | --- |
| 밀도 | 1.2 g/cm³ |

`print("선명하다")`
https://example.com/structure
```

기대 출력

```text
사진 속 글자가 선명하다.
그는 “이 주장은 단단하다”라고 말했다.

| 항목 | 값 |
| --- | --- |
| 밀도 | 1.2 g/cm³ |

`print("선명하다")`
https://example.com/structure
```

선명하다는 시각적 상태를 자연스럽게 표현한다. 물리량, 직접 인용문, 표, 코드와 URL도 보존한다.

## C05. 숨은 영어 원문을 추측하지 않기

판단은 근거 부족으로 유지입니다.

대응 영어는 제공되지 않은 상황입니다.

한국어 입력

```text
이 주장은 단단하다.
```

기대 출력

```text
이 주장은 단단하다.
```

영어와 추가 문맥이 없어 논리적 일관성인지 근거의 충분함인지 확정할 수 없다. 포괄적인 동의어로도 바꾸지 않는다.

## C06. 구체적 행동을 새로 만들지 않기

판단은 근거 부족으로 유지입니다.

대응 영어는 제공되지 않은 상황입니다.

한국어 입력

```text
운영 구조를 설계했습니다.
```

기대 출력

```text
운영 구조를 설계했습니다.
```

무엇을 했는지 특정할 근거가 없다. 담당자를 정했다거나 일정·절차를 바꿨다는 내용을 추가하지 않는다.

원샷 프롬프트는 전체 내용을 붙여 넣은 뒤 끝에 교정할 한국어 원문을 이어 붙여 사용합니다. 스킬은 `SKILL.md`와 `references/rules.json`을 함께 읽을 수 있는 환경에서 교정 원문을 제공해 사용합니다.

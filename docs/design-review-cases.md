# 한국어 문맥에 따른 교정 사례

아래 18개 사례는 교정 기준을 설명하기 위한 기대 출력입니다. 별도 모델에 실행한 결과나 개선율을 나타내지 않습니다. 핵심 사례는 영어 원문 없이 한국어만으로 판단하며, C17은 보조 자료와 사실이 충돌하는 경우를 다룹니다.

실제 교정문은 입력의 문장·문단 수, 줄바꿈·서식·말투를 보존합니다. 아래 코드블록은 입력과 기대 출력을 구별하기 위한 문서 표시입니다.

## C01. 한국어 설명으로 논리적 일관성을 구별

판단은 수정입니다.

한국어 입력

```text
# 검토

앞뒤 설명이 모순되지 않습니다.
- 이 주장은 **단단합니다**.
- 이 판단은 잠정적입니다.
```

기대 출력

```text
# 검토

앞뒤 설명이 모순되지 않습니다.
- 이 주장은 **논리적으로 일관됩니다**.
- 이 판단은 잠정적입니다.
```

앞 문장이 모순이 없다는 뜻을 밝힌다. 제목·목록·강조·빈 줄과 잠정적이라는 유보를 보존한다.

입력과 기대 출력은 모두 마지막 줄 끝의 줄바꿈 한 개를 포함합니다.

## C02. 한국어 설명으로 근거의 충분함을 구별

판단은 수정입니다.

한국어 입력

```text
주장을 뒷받침하는 조사 결과를 충분히 제시했다. 이 주장은 단단하다.
```

기대 출력

```text
주장을 뒷받침하는 조사 결과를 충분히 제시했다. 이 주장은 충분한 근거로 뒷받침된다.
```

앞 문장에서 근거가 충분하다고 이미 밝혔다. 논리에 모순이 없다는 새로운 평가로 바꾸지 않는다.

## C03. 정확한 전문용어 유지

판단은 유지입니다.

한국어 입력

```text
이 작업의 병목은 디스크 쓰기 속도입니다.
```

기대 출력

```text
이 작업의 병목은 디스크 쓰기 속도입니다.
```

병목이 속도를 제한하는 지점을 정확하게 뜻하므로 풀어 쓰거나 바꿀 필요가 없다.

## C04. 문맥에 맞는 표현과 보호 영역 유지

판단은 유지입니다.

한국어 입력

```text
사진 속 글자가 선명하다.
그는 “이 주장은 단단하다”라고 말했다.

| 항목 | 값 |
| --- | --- |
| 밀도 | 1.2 g/cm³ |

`print("선명하다")`
https://example.com/structure
```

기대 출력

```text
사진 속 글자가 선명하다.
그는 “이 주장은 단단하다”라고 말했다.

| 항목 | 값 |
| --- | --- |
| 밀도 | 1.2 g/cm³ |

`print("선명하다")`
https://example.com/structure
```

선명하다는 시각적 상태를 자연스럽게 표현한다. 물리량, 직접 인용문, 표, 코드와 URL도 보존한다.

## C05. 판단의 종류를 알 수 없는 부분 유지

판단은 유지입니다.

한국어 입력

```text
이 주장은 단단하다.
```

기대 출력

```text
이 주장은 단단하다.
```

이 한 문장으로는 논리적 일관성, 근거의 충분함, 반론에 대한 대응력 중 어느 뜻인지 알 수 없다. 영어의 유무가 아니라 판단할 한국어 문맥의 부족이 유지 이유다.

## C06. 구체적 행동을 새로 만들지 않기

판단은 유지입니다.

한국어 입력

```text
운영 구조를 설계했습니다.
```

기대 출력

```text
운영 구조를 설계했습니다.
```

무엇을 했는지 특정할 근거가 없다. 담당자를 정했다거나 일정·절차를 바꿨다는 내용을 추가하지 않는다.

## C07. 질문으로 남는다는 표현에서 알 수 없는 내용 밝히기

판단은 수정입니다.

한국어 입력

```text
환불 가능 여부가 적혀 있지 않습니다. 환불 여부가 질문으로 남습니다.
```

기대 출력

```text
환불 가능 여부가 적혀 있지 않습니다. 환불이 가능한지는 알 수 없습니다.
```

앞 문장의 정보 부족을 근거로 무엇을 알 수 없는지 쓴다. 환불 가능 여부 자체는 결정하지 않는다.

## C08. 다음 단계로 남는다는 표현에서 해야 할 일 밝히기

판단은 수정입니다.

한국어 입력

```text
파일 수정은 끝났습니다. 서버에 올리는 작업이 다음 단계로 남습니다.
```

기대 출력

```text
파일 수정은 끝났습니다. 다음에는 파일을 서버에 올려야 합니다.
```

원문에 이미 있는 다음 작업을 직접 표현한다. 업로드 완료, 새 기한, 담당자를 만들어 넣지 않는다.

## C09. 계속 발생하는 오류를 남는다는 말과 구별

판단은 수정입니다.

한국어 입력

```text
설정을 바꿔도 같은 오류가 반복됩니다. 문제가 계속 남습니다.
```

기대 출력

```text
설정을 바꿔도 같은 오류가 반복됩니다. 같은 오류가 계속 발생합니다.
```

앞 문장의 반복 발생을 뒷문장의 문제에 연결한다. 오류의 원인을 새로 추측하지 않는다.

## C10. 수량·기억·남은 작업·기록의 자연스러운 남습니다 유지

판단은 유지입니다.

한국어 입력

```text
예산이 10만 원 남습니다.
그 장면이 기억에 남습니다.
검토할 항목이 세 개 남습니다.
접속 기록이 로그에 남습니다.
```

기대 출력

```text
예산이 10만 원 남습니다.
그 장면이 기억에 남습니다.
검토할 항목이 세 개 남습니다.
접속 기록이 로그에 남습니다.
```

각 문장에서 남는 대상과 뜻이 명확하다. 남습니다가 반복되더라도 억지로 다른 말로 바꾸지 않는다.

## C11. 뒤 문장이 밝힌 세 항목을 앞 문장에 반영

판단은 수정입니다.

한국어 입력

```text
이 변화는 세 축으로 작동합니다. 신청 기간, 대상, 제출 서류가 바뀝니다.
```

기대 출력

```text
변경 사항은 세 가지입니다. 신청 기간, 대상, 제출 서류가 바뀝니다.
```

뒤 문장에 바뀌는 항목 세 가지가 이미 있다. 축과 작동을 유지할 이유가 없고, 두 문장과 항목은 그대로 보존한다.

## C12. 별도 해설 없이 한국어의 자연스러운 동사 결합 판단

판단은 수정입니다.

한국어 입력

```text
그는 새 옷을 쓰고 출근했다.
```

기대 출력

```text
그는 새 옷을 입고 출근했다.
```

옷과 출근이라는 한국어 문맥만으로 착용 동사를 고를 수 있다. 영어 원문이나 착용 장면이라는 별도 해설이 필요하지 않다.

## C13. 불명확한 부분을 두고 다른 오류 교정

판단은 수정입니다.

한국어 입력

```text
이 주장은 단단하다.
그는 새 옷을 쓰고 출근했다.
```

기대 출력

```text
이 주장은 단단하다.
그는 새 옷을 입고 출근했다.
```

첫 문장의 평가 종류는 확정할 수 없지만 두 번째 문장의 동사 오류는 고칠 수 있다.

## C14. 어색한 상태 표현을 고치면서 판단의 유보 보존

판단은 수정입니다.

한국어 입력

```text
추가 자료가 없어 결론은 확정하기 어려운 상태로 남습니다.
```

기대 출력

```text
추가 자료가 없어 여전히 결론을 확정하기 어렵습니다.
```

어려움이 계속된다는 뜻을 살려 자연스럽게 쓴다. 확정할 수 없다거나 결론이 틀렸다고 단정하지 않는다.

## C15. 글의 장르에 맞는 의도적인 비유 유지

판단은 유지입니다.

한국어 입력

```text
할머니가 떠난 뒤에도 그 말은 마음 한편에 작은 등불로 남습니다.
```

기대 출력

```text
할머니가 떠난 뒤에도 그 말은 마음 한편에 작은 등불로 남습니다.
```

추모하는 문맥에서 기억을 등불에 비유한 표현이 자연스럽다. 정보 전달문처럼 풀어 쓰지 않는다.

## C16. 남습니다 한 단어만 있는 경우 유지

판단은 유지입니다.

한국어 입력

```text
남습니다
```

기대 출력

```text
남습니다
```

대상과 문장이 없어 뜻을 판단할 수 없다. 문맥이 있는 글에서의 교정과 구별한다.

## C17. 보조 자료와 충돌하는 사실을 임의로 변경하지 않기

판단은 유지입니다.

사용자가 함께 제공한 보조 자료

```text
Refunds are not available.
```

한국어 입력

```text
환불이 가능합니다.
```

기대 출력

```text
환불이 가능합니다.
```

제공된 영어와 한국어의 부정이 충돌한다. 문체 교정 과정에서 환불 정책을 임의로 확정하지 않는다.

## C18. 명사로 늘어놓은 행동을 자연스럽게 표현

판단은 수정입니다.

참고 문맥

누가 무엇을 했는지 설명하는 작업 보고다.

한국어 입력

```text
담당자에 의해 자료 검토가 수행되었습니다.
```

기대 출력

```text
담당자가 자료를 검토했습니다.
```

행위자와 행동이 명시된 작업 보고에서 불필요하게 늘인 서술을 고친다. 원문에 없는 행위자를 만들어 넣지 않는다.
